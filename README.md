# waldleben-assets

Öffentliche Dateien für Waldleben e.V., ausgeliefert über GitHub Pages unter
`https://assets.waldleben-muenchen.de/`.

| Datei | Verwendung |
|---|---|
| `gefoerdert-lhm-rbs.jpg` | Logo „gefördert von der Landeshauptstadt München, Referat für Bildung und Sport“ im domainweiten Gmail-Footer für externe Mails (Admin-Konsole → Gmail → Compliance → Fußzeile anhängen). Pflicht nach EKI-Förderrichtlinie 2.3.7. |

**Dateien nicht umbenennen oder löschen**: der Footer verlinkt sie direkt.
Bilder von Google Sites oder Google Drive taugen dafür nicht (wechselnde URLs,
403 bzw. Drosselung bei automatischen Abrufen durch Outlook und Mailfilter).
